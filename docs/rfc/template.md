Como usar este template:

1. Copie este arquivo para "NNNN-titulo-da-proposta.md" na mesma pasta,
   onde NNNN é o próximo número sequencial de 4 dígitos (0001, 0002, ...).
   A numeração de RFC é independente da numeração de ADR (cada pasta
   tem sua própria sequência). Nunca pule, nunca reaproveite um número.
2. Título do arquivo em kebab-case, minúsculo, sem acento
   (ex: 0001-escolha-da-nuvem.md).
3. Use RFC pra decisões grandes, com trade-off real entre alternativas
   (nuvem, banco, estratégia de autenticação) — algo que vale a pena
   comparar opções antes de fechar. Pra decisões pontuais já fechadas,
   use uma ADR em docs/adr/ em vez disso.
4. Uma RFC começa em "Em discussão" e é editada livremente enquanto o
   time comenta. Quando a decisão fecha, muda o Status pra "Aceita" ou
   "Rejeitada" e preenche "Decisão final". Se a proposta virar uma
   decisão arquitetural permanente, registre o resultado também como
   ADR curta em docs/adr/, linkando de volta pra esta RFC.
5. Apague estes comentários ao preencher.
-->
